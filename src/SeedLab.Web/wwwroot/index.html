Where to look

Region is the largest free lever in the tool: a metric bounded by a disc cannot be changed by a cell outside it, so restricting it is exact, not approximate. Measured here at the game’s own 12 m grid, one biome goal costs 7.90 ms/seed inside a 1 km disc against 314.40 ms/seed over the whole world — 39.8×.

      What the map is
      
        
      
          Every tile is generated on demand by the ported WorldGenerator at that zoom's
          own sampling resolution, so zooming in genuinely resolves more terrain instead of
          enlarging pixels. Zoom 3 samples exactly the points the game's own minimap
          samples — 12 m apart — and vseed serve --selftest checks those tiles
          against the biome texture the game itself wrote, pixel for pixel, on two worlds.
        
      
        
      
          Water below 30 m is depth-shaded, the hillshade is Lambert from the height gradient with the
          light at 315°, and Ashlands lava is painted where the cheap mask alpha passes 0.6. The
          biome colours are the game's own measured prefab bytes, with one deliberate change: the game
          paints Deep North pure white, identical to Mountain and Ocean, which makes an offline map
          unreadable, so Deep North is  here. Press
          P for the game's table exactly.
        
      
      
      
      
      
        
      What the markers are
      
        
      
          The markers are the output of the game’s own location placement, re-run offline for
          this seed: the same ordered pass over ZoneSystem.m_locations, the same
          per-type RNG streams, the same eleven filters. Against a freshly generated world it
          reproduces all 12,228 instances bit-identically in zone, prefab and x/y/z, and the
          game’s own per-type counters with them.
        
      
        
      
          A hollow, dashed marker is a candidate, not a place. A
          m_unique type — every trader camp is one — is written into the save
          several times over, and the game keeps whichever one a player (or a peer) generates the
          zone of first, deleting the rest. That is exploration order, not the seed. This map shows
          every candidate and says how many; it will never point at one and call it Haldor.
        
      
        
      
          The height shown is WorldGenerator.GetHeight at the point, which is the y the
          save stores — not the ground a building finally sits on, which comes from the built
          heightmap and the location’s own terrain edits.
        
      
      
      
      
      
        
      Offline and local
      
        
      
          This page came out of vseed's own binary: no CDN, no web font, no external
          request of any kind, and a Content-Security-Policy that forbids one. The server listens on
          127.0.0.1 alone, refuses any other Host and has no CORS policy. It writes a
          results file only where the Search panel says, and otherwise only in its own cache folder:
          checkpoints, map tiles, its logs, and a note that it is running.
